# Лабораторная работа №7. REST API и OpenAPI

## Цель

Предоставить возможности FitCalc через JSON API, описать контракты запросов и
ответов с помощью Pydantic и проверить автоматически формируемую спецификацию
OpenAPI.

## Архитектура

FastAPI подключает маршруты из `fitai/web/api.py` при сборке приложения.
Обработчик плана передаёт проверенный уровень в `WorkoutPlanService` из лабораторной
№5. Сервис формирует план через стратегию `RuleBasedFallback`. Этим же экземпляром
сервиса пользуется форма Jinja2. Схемы API преобразуют результат сервиса в JSON,
а доменные модели остаются классами Python.

План подбирается по уровню, а доступные значения можно получить отдельным
запросом. Сценарий работает без пользовательской учётной записи, хранилища
тренировок и ONNX-модели.

## Маршруты

| Метод и путь | Назначение | Коды ответа |
| --- | --- | --- |
| `GET /api/v1/experience-levels` | Список поддерживаемых уровней с русскими названиями. Параметры отсутствуют. | `200` |
| `POST /api/v1/workout-plans` | Рассчитывает план по уровню из JSON-запроса. | `200`, `422`, `500` |

Для плана используется `POST`, поскольку параметры операции передаются в теле
запроса. План рассчитывается для текущего запроса без сохранения ресурса, поэтому
успешный ответ имеет код `200`.

## Схемы и ошибки

- `ExperienceLevelResponse` описывает значение уровня и подпись для интерфейса.
- `WorkoutPlanRequest` требует поле `level` из набора `beginner`,
  `intermediate`, `advanced`. Неизвестные поля запрещены.
- `WorkoutPlanResponse` возвращает уровень, список строк с упражнениями и
  условную интенсивность в диапазоне от 0 до 1.
- При ошибке валидации FastAPI возвращает `422` и массив `detail` с указанием
  поля, типа ошибки и сообщения. При внутреннем сбое расчёта сервер возвращает
  `500` без диагностических подробностей.

## Запуск и примеры

После установки зависимостей по README запустите приложение из корня:

```bash
python -m uvicorn fitai.web.app:app
curl http://127.0.0.1:8000/api/v1/experience-levels
curl -X POST http://127.0.0.1:8000/api/v1/workout-plans \
  -H 'Content-Type: application/json' \
  -d '{"level":"beginner"}'
```

Пример ответа на запрос плана:

```json
{
  "level": "beginner",
  "exercises": [
    "Ходьба — 10 минут",
    "Приседания к стулу — 2 × 8",
    "Отжимания от стены — 2 × 8"
  ],
  "intensity": 0.35
}
```

FastAPI строит OpenAPI из маршрутов и моделей. После запуска доступны
[Swagger UI](http://127.0.0.1:8000/docs), [ReDoc](http://127.0.0.1:8000/redoc) и
[спецификация JSON](http://127.0.0.1:8000/openapi.json). В Swagger UI можно
открыть операцию и выполнить запрос через **Try it out**.

## Вывод

JSON API и веб-форма используют общий сервис расчёта планов. OpenAPI описывает
маршруты, допустимые уровни, схемы данных и ответы об ошибках.
